Recursion Practicer

Two ways to practice recursion. Approach: build a recursive function from one smaller call, without tracing. Trace: run a function and predict what each call returns.

        How this works
        
    You never trace in this mode. Each step asks one question, using real values. The page checks your answers with a hidden staff solution, which also gives the trusted answers for the smaller calls. At the end it puts your answers together into a function and runs it on tests.
    
      
    
    
    
    
    
      
    
        
    
          
    Steps
    
          
    Pick a smaller input, trust what the function returns for it, build the full answer from that, then add a base case.
